# **App Name**: MediCare

## Core Features:

- Patient Dashboard: Display patient information, appointments, and medical history.
- Doctor Dashboard: Display doctor schedules, patient lists, and appointment details.
- Appointment Scheduling: Allow patients to schedule appointments with doctors based on availability.
- Medical Records Management: Enable doctors to view, update, and manage patient medical records securely.
- Prescription Management: Allow doctors to create and manage prescriptions for patients. The system will automatically check for possible harmful interactions of newly prescribed medications against the patient's medication history, as a tool for safer prescribing practices.
- Billing and Payments: Process medical billing and enable online payments.
- Common Navigation Bar: A unified navigation bar to navigate different sections, with a default sign up option for patients, and a separate sign up option for doctors.
- Dark/Light Mode Toggle: Toggle for switching between dark and light mode, using Shadcn UI.
- Doctor Sign Up: Separate sign-up page for doctors.
- Patient Sign Up: Separate sign-up page for patients.
- Login Page: Common login page for both doctors and patients.
- Admin Console: Separate admin console for managing the system.

## Style Guidelines:

- Primary color: Gentle blue (#64B5F6) to promote a sense of calm and trustworthiness.
- Background color: Very light, desaturated blue (#E3F2FD) to create a clean and professional look.
- Accent color: Soft green (#81C784) to represent health and healing.
- Body and headline font: 'PT Sans', a modern sans-serif to ensure clarity.
- Use simple green and transparent icons.
- Employ a clean and intuitive layout using components from Shadcn UI, ensuring a responsive design.
- Integrate subtle split text animations, along with smooth transitions and loading states.
